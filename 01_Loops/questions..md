# Loop Practice — Questions

## 1. Find index of target

Problem: Write a function that takes an array and a target element and returns the index of the target, or `-1` if not found.

Example: Input: `[3, 5, 7]`, target `5` → Output: `1`

Edge cases: empty array → return `-1`; multiple equal elements → return first index.

Difficulty: Easy

Solution: see [index.js](index.js) and [practice.js](practice.js)

## 2. Count negative numbers

Problem: Write a function that returns the number of negative numbers in an array.

Example: Input: `[4, -1, -3, 2]` → Output: `2`

Edge cases: no negatives → return `0`; non-integer values — clarify expected input types.

Difficulty: Easy

Solution: see [index.js](index.js) and [practice.js](practice.js)

## 3. Largest number in array

Problem: Write a function that returns the largest number in an array.

Example: Input: `[2, 9, 4]` → Output: `9`

Edge cases: empty array — specify behavior (e.g., return `null` or `-Infinity`); all negative numbers.

Difficulty: Easy

Solution: see [index.js](index.js) and [practice.js](practice.js)

## 4. Smallest number in array

Problem: Write a function that returns the smallest number in an array.

Example: Input: `[2, 9, -5]` → Output: `-5`

Edge cases: empty array — specify behavior; mixed types — clarify.

Difficulty: Easy

Solution: see [index.js](index.js) and [practice.js](practice.js)

## 5. Second largest number

Problem: Write a function that returns the second largest number in an array.

Example: Input: `[3, 7, 5]` → Output: `5`

Edge cases: arrays with fewer than 2 unique numbers — specify behavior (e.g., return `null`); duplicates — consider unique values.

Difficulty: Medium
